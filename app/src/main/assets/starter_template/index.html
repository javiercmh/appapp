AI from a subapp

  1. Connect an AI provider in the App² library’s Settings → AI.
  2. Discover providers and models through ai.providers() and ai.models(provider.id).
  3. Choose a model and one of its supported reasoning levels. Provider default omits the effort setting.
  4. Call ai.start(), then wait for the completed text.
  5. Save the text and request ID to data/ai-demo.json before acknowledging the request.
import { ai, writeFile } from './bridge.js';

const { providers } = await ai.providers();
const provider = providers.find(p => p.connected);
if (!provider) throw new Error('Connect a provider in App² Settings → AI.');
const { models } = await ai.models(provider.id);
const id = await ai.start({
  providerId: provider.id,
  model: models[0].id,
  instructions: 'Keep the answer concise.',
  input: 'Write one short sentence explaining what a subapp is.'
});
const text = await ai.wait(id);
if (!writeFile('data/example.json', { id, text })) {
  throw new Error('Save failed; retain the request ID and retry saving.');
}
await ai.acknowledge(id);

The Demo tab implements this flow in js/ai-demo.js. It saves a pending request ID, resumes through ai.result(id), and retries failed saves without another inference.

One request may run or await acknowledgement per subapp. Switching apps keeps its native request running. Closing its task or reloading cancels it. Browser previews show AI as unavailable.

For all return shapes, events, failure handling and lifecycle rules, read AGENTS.md and PACKAGING.md in the editor.

Text to Speech

Use the pronunciation buttons below, or add your own with the speech API. App² uses Android’s configured speech engine; no AI connection is needed.

import { speech } from './bridge.js';
await speech.speak({
  text: 'Hola',
  language: 'es-CL',
  rate: 0.8
});
await speech.stop();

Supply a language for every request. For selected text, annotate each passage: <span lang="es-CL">Hola</span>. App² inherits the nearest lang and rejects selections with missing or conflicting languages.

speech.voices() discovers voice IDs, languages, and whether each voice requires a network connection. speech.available reports the native channel; browser previews cannot play speech.

The Speak promise finishes when playback completes or is cancelled. New speech replaces previous speech; Stop, backgrounding, and reload end playback. Show errors and retry only after a user action. Installed voice data determines available languages.

Try the pronunciation buttons in the Demo tab. Read the Text to Speech section in PACKAGING.md for voice options, failure codes, and lifecycle rules.
